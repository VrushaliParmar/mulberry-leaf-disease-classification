# Dataset

This project uses a dataset of **1,091 mulberry leaf images** belonging to three classes:

- Disease Free — 440 images
- Leaf Rust — 489 images
- Leaf Spot — 162 images

The dataset was divided using a **stratified 70/15/15 split**:

- Training: 763 images
- Validation: 163 images
- Test: 165 images

The original dataset is **not included in this repository**.

To run the project locally, place the dataset in:

dataset/Mulberry_Leaf/
